# Retail 12.1.5 API compatibility audit

Date: 2026-10-14. Release: **7.7.0**. Target: **12.1.5.70391**, interface **120105**. Local installation metadata also reports active Retail build **12.1.5.70391**.

The static review found one cooldown restriction to harden and no other required API migrations in the reviewed addon integrations. Runtime verification on the 12.1.5 client remains pending; local tests do not reproduce WoW's secure execution engine.

## Source versions and coverage

The comparison uses Blizzard's exported UI and generated API documentation at two fixed revisions of the source mirror:

- [12.1.0.69587](https://github.com/Gethe/wow-ui-source/tree/a89e9d0ceb7f6cd31e8fc5ca7df1a338ac0b1b58), matching Mechanic's installed API database.
- [12.1.5.70391](https://github.com/Gethe/wow-ui-source/tree/18c6d677b605b312f3d813d498404631fb941977), the live revision available on the audit date.
- Blizzard's [12.1.5 content update notes](https://news.blizzard.com/en-us/article/24304162/12-1-5-content-update-notes) for the Season 2 context and settings additions.

Scope includes `vesperTools.lua`, every `Core` and `Modules` file, vendored Lua libraries, the TOC/XML load references, registered events, explicit enum references, and Blizzard UI code used by the addon. The source inventory contains **115 distinct C_ API references** and **48 distinct literal event registrations**, including compatibility probes and library callsites. These counts are static references, not executed client probes.

Generated definitions were compared as Lua records, including arguments, return values, event payloads, and restriction flags. APIs absent from generated documentation were reviewed against UI usage or their existing availability checks: Blizzard still uses `C_ToyBox.GetToyInfo`, `GetNumFilteredToys`, and `GetToyFromIndex`; `GetToyIDs` and the legacy challenge-mode probes remain optional. All 48 registered event names remain present in the generated definitions. `Blizzard_Deprecated` has no changes between these revisions.

## Findings and changes

| Area | 12.1.5 finding | Addon handling |
| --- | --- | --- |
| Cooldown setters | `SetCooldown`, its variants, and `Clear` now have `IsProtectedFunction = true`. | Both portal/travel `SetCooldown` callsites now check `IsProtected()` before invoking the setter. Removed the retry that would repeat a rejected call. Ordinary addon cooldown widgets keep their swirl; the numeric countdown remains independent of setter success. |
| Class colors | `C_ClassColor.GetClassColor` adds an optional `tintColor` argument. | Existing one-argument calls remain valid. |
| Spellcast events | `UNIT_SPELLCAST_SUCCEEDED` changes the fourth payload's documented type to `UnitCastBarID`. | The mage travel handler reads the first and third payloads and ignores the fourth. Existing public-number checks remain in place for spell IDs. |
| Animation restrictions | New forbidden aspects restrict animation progress queries and adding animations to restricted groups. Texture restrictions also expand. | New-item glow and configuration effects create and query addon-owned animations/textures. No migration to restricted Blizzard animation groups is needed. |
| Lua helpers | More math/string/table helpers move into native implementations; compatibility aliases remain in shared Lua. | No dependency on removed `C_TableUtil` or `C_StringUtil` symbols was found. Existing standard Lua table/string calls remain supported. |
| Interaction and item enums | Added enum members do not change the bank or weekly-reward values consumed here. `BagFlag.IgnoreSoulbound` is removed. | Explicit enum references still exist; the addon does not use `IgnoreSoulbound`. |
| Duration types | Several duration fields use the `Seconds` documentation type. | No changed argument order or conversion is needed for public numeric cooldown data. |

The cooldown restriction is documented in Blizzard's [cooldown widget API](https://github.com/Gethe/wow-ui-source/blob/18c6d677b605b312f3d813d498404631fb941977/Interface/AddOns/Blizzard_APIDocumentationGenerated/FrameAPICooldownDocumentation.lua). `pcall` catches Lua errors but cannot establish permission to call a protected API. The new guard avoids the call itself; it does not make protected widgets writable.

Animation and texture restrictions are defined by [ForbiddenAspect](https://github.com/Gethe/wow-ui-source/blob/18c6d677b605b312f3d813d498404631fb941977/Interface/AddOns/Blizzard_APIDocumentationGenerated/ForbiddenAspectConstantsDocumentation.lua) and the generated animation/texture widget APIs. Blizzard's [MathUtil](https://github.com/Gethe/wow-ui-source/blob/18c6d677b605b312f3d813d498404631fb941977/Interface/AddOns/Blizzard_SharedXMLBase/MathUtil.lua) and [TableUtil](https://github.com/Gethe/wow-ui-source/blob/18c6d677b605b312f3d813d498404631fb941977/Interface/AddOns/Blizzard_SharedXMLBase/TableUtil.lua) retain their compatibility aliases.

## Feature review

- **Bags and banks:** consumed `C_Container`, `C_Bank`, `C_Item`, item-data events, and category fields retain their contracts. Native container item templates/click handlers are unchanged. Blizzard adds an account-bank access check to its refundable-item confirmation; the addon's live interaction routes already require writable bank access.
- **Mythic+ and roster:** consumed challenge-mode, Mythic+, rating, guild, chat, and party APIs retain their contracts. The Season 2 portal catalog still uses live challenge maps. The patch continues Season 2, so this release does not replace the dungeon rotation or crest family.
- **Great Vault:** consumed weekly-reward APIs and snapshot structures are unchanged. Blizzard fixes its delve tooltip loop to skip empty progress tiers; this addon does not copy that early-return loop. Reward previews continue to prefer live reward hyperlinks over seasonal fallback values. The raid encounter list comes from Blizzard rather than a hard-coded boss roster.
- **Travel and toys:** secure cast buttons, modern spellbook discovery, toy availability fallbacks, and public cooldown-value checks remain applicable. The cooldown setter guard is the only Lua change in this release.
- **Search and settings:** settings discovery reads Blizzard's current category/initializer data. The new minimap coordinates, health pulse, and raid dispel settings do not require a static search catalog update. Talent configuration APIs remain unchanged.
- **Map and group UI:** MapCanvas pin contracts, secure action templates, and compact raid frame integrations are unchanged. The MapCanvas scrolling fix does not alter the lure pin provider. Ready-check UI changes do not change the addon's ready/pull button APIs.
- **Libraries:** reviewed bundled library references against the same source definitions. No library API migration was identified. Mechanic's deprecation scan reports zero findings, but its database targets 12.1.0 and is supplementary evidence only.
